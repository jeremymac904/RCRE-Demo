## Extraction sequence for the receiving workspace

1. Resolve source delivery gap and pin code/test hashes; do not assume GitHub main contains this implementation.
2. Choose one bounded capability and write a tenant-neutral interface around the current tested services.
3. Replace RCRE content/IDs/brand with approved synthetic fixtures. A mortgage NMLS field is not a Realtor license field.
4. Reproduce in a second isolated synthetic tenant with no RCRE config fallback; verify actor scopes and leaks at direct API/export/media URLs.
5. Attach expected failures and provider-disabled modes as acceptance cases. Preserve legal/financial/approval decisions outside model authority.
6. Have an independent reviewer inspect rendered output and actual persistence, not only route status. Record rights and deployment blockers.
7. Only then package a reusable Skill in the ecosystem workspace under its own governance and reviewed version. This task creates no new architecture or installer there.
