# RCRE Platform — River City Real Estate Group OS

Connected digital operating system for **RCRE Group / River City Real Estate Group**, a real estate brokerage operating in Alabama and Florida.

## Features Included
1. **Public Website & Property Search**: Browse listings in Birmingham, Jacksonville, and Ponte Vedra with market filters and property details.
2. **Today & Command Center**: Exceptions-first daily workflow, priority board, and compliance alerts.
3. **CRM & Follow Up Boss Pipeline**: Client database sync, stages, and follow-up tracking.
4. **Transactions & Deal Desk**: Active closing pipeline, document checklists, and signing workflows.
5. **AI Advantage Academy**: 14+ elite Realtor AI courses and training modules.
6. **AI Assistant & Hermes Runtime**: RCRE AI assistant for drafting outreach and reviewing pipeline data.
7. **Recruiting & Team Portal**: Brokerage growth pillars and dual-state coverage details.
8. **Agent Websites**: Showcase of specialized agent websites across themes (Signature, Historic Heritage, New Construction, Urban Modern).
9. **Settings & Integrations**: FUB API status and MLS provider readiness.

## Tech Stack
- React 19 / TypeScript / Vite
- Tailwind CSS styling
- Client-side navigation and responsive UI
