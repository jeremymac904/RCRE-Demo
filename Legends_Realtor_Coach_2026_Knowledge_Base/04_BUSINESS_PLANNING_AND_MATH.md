# Business Planning and Math

## Start With Net Income

Agents often set a volume goal without understanding what they need to keep.

Start with the desired annual net income.

Then estimate:

Business expenses.

Cost of sales.

Taxes with professional guidance.

Marketing.

Technology.

Team expense.

Training.

Required GCI.

## Reverse Engineer The Goal

A useful sequence is:

1. Desired net income.

2. Required GCI.

3. Average GCI per closed transaction.

4. Required closed transactions.

5. Buyer and seller mix.

6. Required signed clients.

7. Required appointments.

8. Required meaningful conversations.

9. Required daily activity.

## Example

Assume an agent wants $180,000 in GCI.

Average GCI per closing is $7,500.

Required closings are 24.

If half are buyer sides and half are seller sides, the target is 12 buyer closings and 12 seller closings.

If 75 percent of signed buyer clients eventually close, the agent needs about 16 signed buyer clients.

If half of buyer consultations create a signed client, the agent needs about 32 buyer consultations.

Use the same logic for listings.

These conversion assumptions must be replaced with the agent's actual numbers as soon as reliable data exists.

## The 1 3 5 Plan

The supplied EXP and Cannonball material uses a simple 1 3 5 structure.

1 main objective.

3 priorities required to achieve the objective.

5 strategies or action items under each priority.

This is useful because it forces the agent to reduce complexity.

### Example

Main objective:

Close 30 transactions in the next 12 months.

Priority 1:

Grow database driven business.

Actions:

Complete database cleanup.

Contact 25 sphere contacts per week.

Ask for referrals.

Run a monthly homeowner value campaign.

Hold one client event per quarter.

Priority 2:

Build listing business.

Actions:

Practice listing presentation.

Call expireds.

Call FSBOs.

Run local seller content.

Track listing conversion.

Priority 3:

Build authority.

Actions:

Publish three short videos per week.

Publish one local market video per week.

Collect two reviews per month.

Improve Google Business Profile.

Create one neighborhood content series.

## Conversion Math

Track actual ratios.

Conversation to appointment.

Appointment to signed client.

Signed client to contract.

Contract to close.

Listing appointment to listing taken.

Listing taken to listing sold.

Small improvements in conversion can create a major increase in income without increasing lead volume.

That principle appears throughout the supplied coaching material.

## The CEO Review

At the end of each week ask:

Did the calendar reflect the goal?

Did the agent do the required lead generation?

Did the agent practice the required skills?

Did the pipeline improve?

Did the database grow?

Did the agent create more appointments?

Did the business create profit?

What should change next week?

## Rule

A business plan that does not translate into weekly behavior is only a wish.
