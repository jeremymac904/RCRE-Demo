# Database and Referrals

## The Database Is An Asset

The database is not simply a contact list.

It is a record of relationships, opportunities, context, and future business.

Current NAR technology research identifies CRM as one of the strongest technology sources for quality leads.

Current Tom Ferry Elite coaching places strong emphasis on referral business and a fully systemized database.

The supplied coaching library also repeatedly emphasizes past clients, VIP relationships, sphere calls, handwritten notes, events, and referral requests.

## Database Categories

Use simple categories.

Past clients.

Sphere.

Active buyers.

Active sellers.

Warm leads.

Long term nurture.

Referral partners.

Agents.

Local businesses.

Vendors.

Investors.

Do not overcomplicate tags.

## Minimum Contact Record

Name.

Phone.

Email.

Relationship.

Location.

Real estate status.

Last contact.

Next action.

Relevant personal notes.

Lead source.

Consent status where applicable.

## Relationship Rhythm

The exact cadence can vary.

High value relationships deserve more personal contact.

Examples:

Phone.

Text.

Video message.

Coffee.

Lunch.

Client event.

Handwritten note.

Home anniversary.

Market update.

Home value review.

Referral request.

The database should not be touched only through generic newsletters.

## Referral Moments

The supplied coaching material highlights natural referral triggers.

Examples:

The client compliments service.

A problem is solved.

A negotiation goes well.

The listing launches.

The buyer gets under contract.

A difficult issue is resolved.

Closing is approaching.

Closing is complete.

The client leaves a positive review.

A referral request should feel connected to value already delivered.

## Referral Language Principle

Do not make the request complicated.

A useful structure is:

Acknowledge the positive result.

Connect it to the service standard.

Ask who else may need the same help.

## Past Lead Reactivation

Old leads are not automatically dead.

Segment by reason they did not move.

Timing.

Financing.

Inventory.

Job.

Relationship.

Rate concern.

Home sale contingency.

Then reach out with a relevant reason.

## Homeowner Value Campaign

A strong database system can include a periodic property value conversation.

The purpose is not to spam automated valuations.

The purpose is to create a homeowner conversation.

Possible topics:

Equity.

Neighborhood activity.

Renovation impact.

Move timing.

Investment property.

Refinance conversation with an appropriately licensed mortgage professional.

A database that is never contacted is not a database strategy.
