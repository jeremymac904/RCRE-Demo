# RCRE Technology Inventory

**For RCRE to complete.** Whoever knows the systems best — office manager, admin, or whoever pays the
bills — is usually the right person.

**Blanks are completely fine.** "Not sure" and "we don't have one" are useful answers. Do not go
hunting for exact figures; approximate is fine.

Should take 20–30 minutes.

---

## How to fill this in

For each system, tell us as much as you easily can:

| Field | What we mean |
|---|---|
| **Product** | The name. "Not sure" is fine. |
| **Who uses it** | Everyone / agents only / leadership / admin / one person |
| **Who pays** | Brokerage / agent pays their own / mixed |
| **Cost** | Roughly, per month or year. Skip if unknown |
| **Importance** | **Critical** (business stops) · **Important** · **Nice to have** · **Barely used** |
| **What you like** | One line |
| **What you hate** | One line — this is the most useful column |
| **Replace it?** | **Yes** / **No** / **Maybe** / **Please** |
